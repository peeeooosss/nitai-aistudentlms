# Creating Visual Brand Assets

## Learning Objectives
- Design a complete brand visual identity using AI tools
- Create logos, social media templates, and marketing materials
- Build a scalable brand system with consistent visual language
- Package and deliver brand assets professionally

---

## Brand Identity Fundamentals

A brand identity is more than a logo. It is a complete visual system that communicates who you are, what you do, and how you make people feel.

### The Brand Identity Stack
```
Layer 1: Logo (primary mark, wordmark, icon)
Layer 2: Colors (primary, secondary, accent, neutrals)
Layer 3: Typography (heading, body, accent fonts)
Layer 4: Imagery (photo style, illustration style, icons)
Layer 5: Layout (grids, spacing, composition rules)
```

### Starting with Strategy
Before designing anything, answer these questions:
1. **Who** is your target audience? (age, interests, profession)
2. **What** do you do? (one sentence)
3. **How** do you want people to feel? (professional, playful, innovative, trustworthy)
4. **What** makes you different? (unique value proposition)
5. **What** brands do you admire? (aesthetic references)

## Logo Design with AI

### Logo Prompt Framework
```
Design a [style] logo for [company name], a [type of business].

The logo should:
- Communicate [core values: innovation, trust, creativity]
- Appeal to [target audience]
- Work at small sizes (favicon, app icon) and large (billboard)
- Be [minimal/detailed/abstract/symbolic]

Colors: [brand colors or "suggest colors"]
Style: [modern/classic/playful/luxury/technical]
Include: [specific elements or "keep it abstract"]
```

### Logo Design Process
1. **Generate 20+ concepts** — quantity leads to quality
2. **Narrow to 5** — based on memorability, versatility, and relevance
3. **Refine the top 3** — iterate on details, colors, proportions
4. **Final selection** — test at different sizes and on different backgrounds

### Logo Variations to Create
```
Primary: Full logo (icon + wordmark)
Secondary: Icon only (for small spaces)
Horizontal: Wordmark only (for headers)
Dark: White version for dark backgrounds
Light: Dark version for light backgrounds
Favicon: Simplified icon for browser tabs
```

## Marketing Material Templates

### Business Card Design
```
Design a business card for [name], [title] at [company]:

Front: Logo, name, title, tagline
Back: Contact info, website, social handles

Style: [minimal/luxury/creative/technical]
Colors: [brand palette]
Special considerations: [foil stamp, rounded corners, etc.]
Dimensions: 3.5 x 2 inches (US standard)
```

### Presentation Template
```

Slide 1: Title slide (logo, title, presenter)
Slide 2: Agenda/overview

Slide 8: Data/statistics slide
Slide 9: Call-to-action
Slide 10: Thank you / contact

Brand elements: [colors, fonts, logo placement]
Style: Clean, professional, data-friendly
```


## The Brand Guidelines Document

A brand guidelines document ensures consistency across all creators and platforms.

### What to Include
```
1. Brand Overview
   - Mission statement
   - Brand personality
   - Target audience

2. Logo Usage
   - Primary logo and variations
   - Minimum size requirements
   - Clear space rules
   - Do's and don'ts

3. Color Palette
   - Primary colors (with hex, RGB, CMYK codes)
   - Secondary colors
   - Color usage rules
   - Accessibility considerations

4. Typography
   - Primary font (headings)
   - Secondary font (body)
   - Font sizes and weights
   - Line spacing and hierarchy

5. Imagery
   - Photo style guidelines
   - Illustration style
   - Icon style
   - Image treatment (filters, overlays)

6. Templates
   - Social media templates
   - Presentation templates
   - Email templates
   - Marketing materials
```

## Delivery Package

### File Formats to Deliver
```
Logo:
- SVG (vector, infinitely scalable)
- PNG (transparent background, multiple sizes)
- JPG (for non-transparent needs)
- PDF (for print)

Colors:
- Hex codes (#RRGGBB)
- RGB values (for screens)
- CMYK values (for print)

Fonts:
- TTF/OTF files (if licensed)
- Google Fonts links (if web fonts)
- Fallback font recommendations

Templates:
- Canva links (editable by client)
- Figma files (for designers)
- PNG/PDF exports (for immediate use)
```

## Key Takeaways

- Brand identity is a complete system: logo, colors, typography, imagery, and layout
- Generate volume first (20+ concepts), then refine and narrow
- Create all logo variations: primary, icon, horizontal, dark, light, favicon
- Build template systems for social media, presentations, and marketing materials
- Deliver a brand guidelines document to ensure consistency

## Practice Challenge

1. Choose a fictional business and define its brand strategy (who, what, how, different)
2. Design a complete logo system (primary + 5 variations) using AI tools
3. Create 5 Instagram post templates and 1 LinkedIn banner
4. Package everything into a delivery folder with a brand guidelines document
