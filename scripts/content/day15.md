# AI Video Script Writing

## Learning Objectives
- Write compelling video scripts using AI assistance
- Understand video script structures for different platforms
- Master hooks, pacing, and calls-to-action in video content
- Build a repeatable video production workflow

---

## Why Video Content Matters

Video is the dominant content format in 2026. Short-form video (TikTok, Reels, Shorts) drives the highest engagement. Long-form video (YouTube) builds the deepest authority.

### Video Content Statistics
- Video content generates 1200% more shares than text and images combined
- 91% of consumers want to see more online video content from brands
- YouTube is the second largest search engine after Google
- TikTok averages 95 minutes per user per day

AI makes video scripting fast. You go from idea to polished script in minutes, not hours.

## Video Script Structures

### Short-Form (15-60 seconds)
```
Hook (0-3 seconds):
  Stop the scroll. Bold claim, surprising fact, or visual hook.

Content (3-50 seconds):
  Deliver ONE idea. No tangents. Fast pacing.

CTA (last 5 seconds):
  What should they do next? Follow, save, comment, link in bio.
```

### Medium-Form (1-5 minutes)
```
Hook (0-10 seconds):
  Promise a specific outcome or answer a burning question.

Setup (10-30 seconds):
  Establish context. Why should they care?

Content (30-200 seconds):
  3-5 key points. Each point = claim + example + transition.

Summary (last 15 seconds):
  Recap the key takeaways.

CTA (last 5 seconds):
  Subscribe, comment, visit link.
```

### Long-Form (5-20 minutes)
```
Hook (0-30 seconds):
  Strong hook + preview of what they will learn.

Introduction (30-90 seconds):
  Context, credibility, what to expect.

Main Content (segments of 3-5 minutes each):
  Each segment = mini hook + content + transition.

Recap (last 1-2 minutes):
  Summary of all key points.

CTA (last 30 seconds):
  Subscribe, related videos, resources, next steps.
```

## AI Video Script Prompts

### YouTube Script
```
Write a YouTube video script about [topic].

Target length: [5/10/15] minutes
Audience: [who is watching]
Goal: [what they should learn/do after watching]

Structure:
1. Hook (0-30 sec) — something that makes them keep watching
2. Introduction — context and what they will learn
3. Main content — [number] key points with examples
4. Recap — summarize takeaways
5. CTA — subscribe, comment, resources

Tone: [energetic/calm/educational/entertaining]
Include: [B-roll suggestions, visual cues, on-screen text]
```

### TikTok/Reels Script
```
Write a 30-second TikTok script about [topic].

Structure:
1. Hook (first 2 seconds) — visual or verbal attention-grabber
2. Core message (25 seconds) — ONE idea, fast-paced
3. CTA (last 3 seconds) — follow, save, comment

Include:
- On-screen text overlays
- Suggested background music mood
- Visual transition cues
- Estimated word count (60-80 words for 30 seconds)
```

### Explainer Video Script
```
Write an explainer video script for [product/service/concept].

Length: 2 minutes
Audience: [beginners/intermediate/expert]
Tone: [professional/friendly/technical]

Structure:
1. Problem statement — what pain point exists?
2. Solution introduction — what is the answer?
3. How it works — step by step
4. Benefits — why it matters
5. Social proof — who else uses this?
6. CTA — what to do next

Include visual directions for each section.
```

## The Script-to-Screen Workflow

### Step 1: Ideation (5 minutes)
```
I want to make a video about [topic].

Generate 5 different angles/hooks for this topic:
1. Educational angle
2. Contrarian angle (challenge common belief)
3. Story-driven angle (personal anecdote)
4. List-based angle (X tips, mistakes, etc.)
5. Comparison angle (this vs. that)

For each, suggest the best platform (YouTube/TikTok/LinkedIn).
```

### Step 2: Script Writing (10 minutes)
```
Write a complete script for this angle: [chosen angle]

Platform: [YouTube/TikTok/Instagram]
Length: [target duration]
Include:
- Exact words to say (conversational, not formal)
- [B-roll/visual] cues in [brackets]
- [On-screen text] cues in {curly braces}
- Pacing notes (speed up, slow down, pause)
```

### Step 3: Teleprompter Format (5 minutes)
```
Convert this script into teleprompter format:
- Short lines (5-8 words per line)
- Natural pause points marked with /
- Emphasis words in CAPS
- Difficult words phonetically spelled

Script: [paste your script]
```

### Step 4: Thumbnail and Title (5 minutes)
```
Generate 10 YouTube video title options for a video about [topic].

Mix these styles:
- Curiosity gap ("I tried X for 30 days...")
- Number-based ("5 mistakes everyone makes with X")
- How-to ("How to X without Y")
- Bold claim ("The truth about X nobody tells you")
- Question ("Is X actually worth it?")

For each title, suggest a matching thumbnail concept.
```

## Video Content Repurposing

### One Video, Many Pieces
```
Video (10-minute YouTube)
  -> Short clips (3-5 TikToks/Reels)
  -> Blog post (transcript + editing)
  -> Twitter thread (key points)
  -> LinkedIn article (condensed insights)
  -> Newsletter section (video highlight)
  -> Quote graphics (best lines)
```

### AI Repurposing Prompt
```
Here is a video transcript: [paste transcript]

Repurpose into:
1. 3 short-form video scripts (15-30 seconds each)
2. A blog post outline (based on key points)
3. A Twitter thread (7 tweets)
4. 5 quote graphics (punchy one-liners)

Maintain the core message but adapt for each format.
```

## Key Takeaways

- Video script structure varies by platform: short-form (hook + content + CTA), long-form (hook + setup + segments + recap)
- AI accelerates ideation, scripting, and repurposing — go from idea to script in minutes
- The hook is everything — you have 2-3 seconds to earn attention
- Include visual cues in scripts — video is a visual medium
- Repurpose one video into 5-10 pieces of content across platforms

2. Write a 5-minute YouTube explainer script on the same topic
3. Convert one script into teleprompter format
4. Repurpose the script into a blog outline and 7-tweet thread
