## Certification Review Exercises

### Exercise 1: Architect from Scratch (no prompts)
Write out, from memory, the architecture of:
- An agent (ReAct loop) with tools, memory, and guardrails
- A support automation system (pipeline with RAG)
- A multi-agent content team (CrewAI roles + tasks)

### Exercise 2: Code Recall
Without looking, write a minimal function-calling agent loop in Python (the `run_agent` pattern from Day 44). Then compare against the reference.

### Exercise 3: Decision Scenarios
Decide the right answer for each:
- Client wants a privacy-sensitive support bot → n8n (self-host) or Make? Why?
- Task is "deterministic, exact steps" → agent or fixed automation?
- Client needs weekly executive reporting → what system do you build?
- Need to check AI content didn't hallucinate → what QA check?

### Exercise 4: Tool Selection
Given these needs, name the tool/technique:
1. Turn a PDF invoice into structured data → ?
2. Store + semantically search agent memories → ?
3. Repurpose a video into 10 posts → ?
4. Let users query data in plain English → ?
5. Auto-send a weekly report → ?

### Exercise 5: Business Case
Write a one-page proposal outline for selling "customer support automation" to a small SaaS company. Include the problem, solution, ROI, pricing, and risk reversal.

## Common Pitfalls to Revisit

- **Jumping to build** instead of mapping the workflow first (Day 32)
- **Not keeping humans in the loop** for judgment calls (Day 32, 57)
- **Letting the agent loop forever** — always set a max step limit (Day 41, 44)
- **Hallucination** — always ground in a knowledge base / source, never trust output blindly (Day 35, 45, 57)
- **Scope creep** — manage scope changes explicitly (Day 55)
- **Silence during delivery** — the weekly update is non-negotiable (Day 55)
- **Not tracking revenue/margins** — know which clients are worth keeping (Day 56, 59)
